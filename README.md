### 02 / Featured Projects

A selection of things I've been building and experimenting with.

#### PS4-rPKG
[Repository ↗](https://github.com/neeitr0n/ps4-rpkg)

A Linux-based remote PKG installer for PlayStation 4.

Provides a local web interface for managing installation queues, selecting packages, communicating with the console, and monitoring file transfers over HTTP.

`Python` `HTTP` `HTML` `Linux`

#### PS4-RPI-Payload
[Repository ↗](https://github.com/neeitr0n/ps4-rpi-payload)

A lightweight, resident Remote Package Installer background payload for jailbroken PS4 consoles.

Enables remote PKG installation through HTTP requests without launching a foreground RPI application, allowing installations to run in the background while using the console.

`C` `HTTP` `PS4 SDK` `Low-level Development`

#### AegisVLESS
[Repository ↗](https://github.com/neeitr0n/AegisVLESS)

An automated VLESS Reality management daemon for 3x-ui panels.

Features dynamic SNI and port rotation, client migration, synchronized firewall rules, a multilingual WebUI, and a built-in subscription server.

`Python` `Linux` `systemd` `Networking` `WebUI`

#### TorTunnel
[Repository ↗](https://github.com/neeitr0n/TorTunnel)

A Linux utility for routing system traffic through the Tor network using obfs4 bridges.

Automates Tor configuration, bridge rotation, connectivity monitoring and recovery, IPv6 blocking, and DNS leak protection. Supports both nftables and iptables.

`Python` `Linux` `Tor` `Networking` `Firewall`
